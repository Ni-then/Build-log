NoSQL

Data schema-less / flexible schema hota hai (har document ka structure alag ho sakta hai)
Data usually JSON-like documents mein store hota hai
Example: MongoDB

SQL

Data tables (rows aur columns) mein hota hai
Fixed schema hota hai, aur columns ke types strict hote hain (INT, VARCHAR, etc.)
Example: PostgreSQL, MySQL

Interview question : 
You might think that mongoose does add strictness to the codebase because we used to define a schema there. 
That strictness is present at the Node.js level, not at the DB level. You can still put in erroneous data in the database that doesn’t follow that schema.
