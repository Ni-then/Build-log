SHA - 256 (256 bits)
Ye ek hash function hai: koi bhi input do, ye hamesha 64 hex characters ka output deta hai.

examples : 
"hello" → 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
"hello1" → 91e9240f415223982edc345532630710e94a7f52cd5f48f5ee1af3f4c8a9d2b1 (bilkul alag, bas ek character badla)

Do zaroori properties:

One-way hai: hash dekh ke input wapas nahi nikal sakte.
Unpredictable hai: input me chhota sa change karo, to output poora random jaisa badal jata hai.
